# outputs/

`python -m medclaim analyze` 결과가 저장됩니다 (git 제외).

- `report.md` — 전체 리포트 (데이터 현황 · 코딩 신뢰도 · RQ1 · RQ2 · RQ3 · 텍스트마이닝 · 분류)
- `tables/*.csv` — 표 원자료 (`analysis_dataset.csv` = 기사 단위 분석용 전체 데이터)
- `figures/*.png` — 강도 사다리, 매체 유형별 비율, 조건 유지율 히트맵, 댓글 반응

합성 데이터 데모 결과 예시는 `docs/demo/` 에 있습니다.
