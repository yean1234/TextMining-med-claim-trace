# 코딩 지침 (Codebook) v0.1

사람 코더가 `annotation/paper_coding.csv`, `annotation/article_coding_<코더>.csv` 를 채울 때의 기준입니다.
Sumner et al.(2014)의 척도를 한국어 기사에 맞게 옮겼고, **조건 누락·출처 오류 항목은 우리가 추가한 것**입니다
(발표할 때 Sumner 의 기존 척도라고 설명하면 안 됩니다).

> 진행 방식: 먼저 **5개 묶음으로 예비 코딩** → 두 코더가 독립 코딩 → κ 확인 → 애매했던 사례를 이 문서의
> '판단 규칙'에 추가 → 본 코딩. 전체의 최소 30%(가능하면 전부)를 두 명이 독립 코딩합니다.
> 목표 κ ≥ 0.70. 낮으면 지침을 고치고 다시 코딩합니다.

---

## A. 분석 단위

| 단위 | 범위 | 비고 |
|---|---|---|
| 논문 | **초록의 결론(Conclusions) 구간**, 필요하면 Discussion 첫 문단 | 결론부의 '첫 주장 문장'이 주 주장 |
| 기사 제목 | 제목 전체 (부제 제외) | |
| 기사 리드 | 본문 **첫 두 문장** (바이라인·사진설명 제외) | Sumner: 제목 + 첫 두 문장 |
| 기사 본문 | 전체 | 주의 문장(caveat)·조건·권고 판단용 |

**목표 관계** = 그 묶음의 '약물 → 결과(부작용)' 관계. 다른 관계(예: 질환 자체의 유병률)에 대한 문장은 코딩하지 않습니다.

## B. 인과 표현 강도 (title_strength, lead_strength, paper_strength) — 0~6

| 값 | 범주 | 정의 | 한국어 예 |
|---|---|---|---|
| 0 | 진술 없음 | 목표 관계에 대한 진술이 없음 | "트럼프가 틀렸다" (그 자체만) |
| 1 | 관계 없음 | 관계가 없다고 명시 | "자폐와 연관성 없어", "타이레놀 괴담?", "인과관계 회의적", "유발하지 않는다" |
| 2 | 상관 | 연관·관련·통계적 차이를 서술 | "연관성이 관찰됐다", "위험이 1.33배 높은 것으로 나타났다", "관련 있어" |
| 3 | 모호 | 관계를 암시하지만 성격이 불분명 / 명사형 | "치매 위험…1.3배 발병률 상승", "'시력 손실' 부작용", "연결고리", "자칫하단 '실명위험'" |
| 4 | 조건부 인과 | might/may: 가능성·우려 | "유발할 가능성", "치매 우려", "높아질 수도 있다" |
| 5 | 인과 가능 | can: ~할 수 있다 | "유발할 수 있다", "위험이 높아질 수 있다" |
| 6 | 단정적 인과 | 원인·결과를 단정 | "실명 위험 높여", "치매 부른다", "유발한다", "위험 낮춘다" |

**판단 규칙**
1. 한 단위에 여러 주장이 있으면 **목표 관계에 대한 가장 강한 주장**을 코딩한다.
   예) "연관성 있어도 원인 아냐" → 2 (연관은 인정, 인과는 부정 → 가장 강한 긍정 주장 = 상관).
2. **의문형 제목**("심각한 정신 질환 유발?")은 물음 안의 주장 강도로 코딩한다(→6). 의문형 여부는 자동 변수
   `auto_title_question` 으로 따로 분석한다.
3. **인용문도 기사의 진술로 코딩**한다(Sumner 와 같음). 따옴표 제목 여부는 `auto_title_quoted` 로 따로 남는다.
4. 통계 결과 서술("~배 높은 것으로 나타났다", "~% 낮았다")은 2. 같은 수치라도 동사 없이 명사로 끝나는
   헤드라인("위험 1.3배", "발병률 상승")은 3.
5. "~하면 ~ 높아진다", "~ 키운다/부른다/높여"는 6. "~할 수 있다"는 5. "가능성·우려·~수도 있다"는 4.
6. RCT 논문이 인과를 말하면 논문 강도 자체가 6이다(정당한 인과). 과장 판정은 **논문 대비 상대값**이다.
7. 논문 강도는 결론부 **첫 주장 문장** 기준. 예) Ahlqvist 2024: "...was not associated ... in sibling control
   analysis" → 1.

## C. 방향 (direction, paper_direction)

`inc`(위험 증가) / `dec`(위험 감소) / `null`(관계 없음) / `unclear`. 사례4(세마글루타이드-자살충동)는 `dec`.

## D. 행동 권고 (advice) — 기사 전체에서 가장 강한 것

| 값 | 정의 | 예 |
|---|---|---|
| 0 | 권고 없음 | |
| 1 | 암묵적 권고 | "주의가 필요하다", "신중한 처방이 요구된다", "안전성 검토 필요" |
| 2 | 의료진 대상 명시적 권고 | "의사는 처방 시 ~를 고려해야 한다" |
| 3 | 독자(일반인) 대상 명시적 권고 | "복용을 중단하라", "의사와 상담하세요", "임의로 끊지 말라" |

'끊지 말라'처럼 안심 방향 권고도 3입니다(방향이 아니라 명시성을 봄).

## E. 본문 주의 문장 (caveat_in_body) — Y/N

본문 어디든 다음 중 하나가 있으면 Y: 인과관계 유보("인과관계는 추가 연구 필요"), 연구 한계, 해석 주의,
"~를 끊어야 한다는 의미는 아니다", 교란 요인 언급. → 제목 강도 ≥5 이면서 Y 이면 **제목-본문 불일치**(사례1)로 집계.

## F. 제목의 조건 생략이 오해를 부르나 (title_omission_misleading) — Y/N/NA

- 먼저 `paper_coding.csv` 의 `key_conditions` 를 본다(그 논문을 정확히 전하려면 꼭 필요한 조건).
- **Y**: 제목만 읽은 독자가 적용 범위를 잘못 이해할 가능성이 높다.
  예) B01 "PPI제제 **장기** 복용시 치매 위험…1.3배" — 논문은 '누적 4.4년 초과'에서만, 전체 복용자는 유의하지 않음 → Y
- **N**: 조건이 빠졌지만 제목이 그 조건 없이도 오해를 부르지 않는다(예: 관계 없음 제목).
- **NA**: 논문에 핵심 조건이 없다.
- '조건 미언급'(자동 탐지)과 '오해 유발'(이 변수)은 다르다. 제목에 모든 조건을 넣을 수는 없다.

## G. 동물→인간 일반화 (animal_generalization) — 동물·세포 연구만

`0` 동물/세포임을 명시 · `1` 인간에게 적용되는 것처럼 암시 · `2` 인간에게 적용된다고 명시 · `NA` 동물연구 아님

## H. 출처 표기 오류 (source_error) — Y/N

저널명·연구기관·저자를 틀리게 적었으면 Y. 예) B06 하이닥: 저널을 'Psychiatrist.com'(웹사이트)으로 표기 → Y.
자동 열 `non_journal_sources` 가 후보를 보여준다.

## I. 논문 시트 (paper_coding.csv)

| 열 | 값 |
|---|---|
| design | observational / rct / animal / in_vitro / meta / review / case_report / pharmacovigilance / other |
| paper_strength | B 의 0~6 |
| paper_direction | inc / dec / null / unclear |
| key_conditions | `population; animal; sample_size; dose; duration; design; effect_size; limitation` 중 필요한 것을 `;` 로 |
| key_conditions_detail | 구체 값 (예: "누적 4.4년 초과에서만 HR≈1.33, 현재 복용자 전체 HR 1.1(0.9–1.3)") |
| main_finding_ko | 한국어 한 줄 요약 (코딩 시트에 '논문 결론'으로 표시됨) |
| paper_caveat | 저자가 밝힌 주요 한계 |
| press_release_url / press_release_strength | (선택) EurekAlert 등 보도자료가 있으면 그 강도 0~6 — Sumner 식 '보도자료 단계' 비교 |

## J. 기사 후보 시트 (article_candidates.csv)

| 열 | 값 |
|---|---|
| include | Y / N |
| link_type | `main`(이 논문을 주로 보도) / `background`(다른 소식을 다루며 이 논문을 배경으로만 인용) / `unrelated` |
| paper_match_evidence | 연결 근거: 저널명, 연구팀·저자, 표본 수, 발표 시점 등 |

`include=Y` 이고 `link_type` 이 background/unrelated 가 아닌 기사만 본문을 수집합니다(헷갈리지 않게 main 을 꼭 적으세요). 원논문을 확인할 수 없는 기사는 '허위'가 아니라
'근거 확인 불가'로 제외(N)하고 `candidate_notes` 에 적습니다.
