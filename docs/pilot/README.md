## 3. 인사이트 (n=18, 묶음 5개 — 방향을 보는 수준)

1. **과장은 '위험이 있다'는 논문에 몰린다.** 위험 증가를 보고한 논문(B01 PPI-치매, B04 위고비-NAION, B06 탈모약-우울)의
   기사 제목 10건 중 9건이 논문보다 강했다(예: 논문 '연관' 2 → "치명적 부작용 확인", "주사 맞고 실명?" 6).
   반대로 '연관 없음/위험 감소' 논문(B03 타이레놀, B05 위고비-자살) 기사 8건은 0건.
2. **대신 '연관 없음' 논문은 확실성이 과장된다.** "최종 판명", "논란 종결?", "트럼프가 틀렸다", "자살 충동 위험 없다".
   Sumner 7범주로는 모두 1(관계 없음)이라 안 잡힌다 → **'확실성 강화' 변수를 추가할지** 팀 결정 필요.
   특히 B05 는 논문이 "더 낮은 위험과 연관"인데 기사 3건 모두 "위험 없음/무관"으로 바꿨다(방향 변화).
3. **제목-본문 불일치가 재현된다.** 강한 제목(≥5)인데 본문엔 '인과는 추가 연구 필요' 같은 주의 문장이 있는 기사 22%(4/18).
   노션 사례1(메디칼타임즈 PPI)도 같은 형태다: 제목은 명사형(3)이지만 리드는 "치매 위험을 높인다"(6), 본문은
   "연관성 분석일 뿐", "끊어야 한다는 의미 아님".
4. **조건 누락은 '언급 여부'로는 안 보인다.** B01 제목의 '장기 복용'은 자동 탐지상 '기간 언급 있음'이지만 실제 조건은
   '누적 4.4년 초과'. 사람 판정으로는 제목의 조건 생략이 오해를 부르는 기사가 50%(9/18).
5. **출처 오류가 생각보다 흔하다(22%, 4/18).** 위고비-자살 기사 3건 모두 데이터를 'FAERS'로 오기하거나 '노보노디스크가
   발표'라고 썼다(원논문은 케이스웨스턴·NIDA 의 전자건강기록 연구). 하이닥은 저널을 'Psychiatrist.com'으로 표기.
6. **노션 사례 중 일부는 '같은 논문, 다른 제목'이 아니었다.** 사례5의 데일리메디 "인과관계 회의적"은 2020년 다른 논문
   (JAMA Dermatology) 관련 기사, 사례3의 약사공론 "시력 손실…안전성 검토 필요"는 2025년 유타대 9명 사례 논문 기사,
   사례2의 메디칼타임즈 "연관성 있어도 원인 아냐"·문화일보 "괴담?"은 2025년 트럼프 발언 해설이었다.
   → 묶음은 반드시 본문으로 연결을 확인해야 한다.
7. **매체 유형 차이는 힌트만.** 인터넷 매체 4건은 전부 논문보다 강한 제목(평균 6.0), 의약전문지 5건은 40%.
   묶음·매체 수가 작아 통계적 결론은 불가(GEE 는 표본 부족으로 생략).
8. **통신사 재인용.** 한국경제·아시아경제 기사는 연합뉴스 기사를 받아쓴 것이다 → 기사 수가 늘어도 독립 표본이 아닐 수 있다.

## 4. 리포트 읽는 법 (팀원 공유용)

1. **0-1 점검표**부터: ⚠️ 항목이 병목이다(이번엔 B02 기사 부족, 자동 사전의 권고·주의 문장 판별).
2. **2-3 묶음별 표**: 논문 강도 vs 제목 강도 min~max. 묶음마다 '얼마나 갈라지는지'가 핵심 그림이다(strength_ladder.png).
3. **2-1 전체 비율**: 대괄호는 묶음 단위 부트스트랩 95% CI. 지금처럼 [14, 94]%로 넓으면 **방향만** 말하고 수치는 말하지 않는다.
4. **3 조건 표**: '제목에서만 빠짐'이 높을수록 RQ2 근거. 자동 탐지값이므로 사람 판정 비율(점검표)과 같이 본다.
5. **1 코딩 신뢰도**: auto vs 코더 κ 가 낮은 항목은 자동 결과를 믿지 않는다.
6. **5 텍스트마이닝**: 사람 판정으로 과장을 정한 뒤의 보조 증거다. 순서를 거꾸로(단어 → 과장 판정) 하면 순환 논리.

## 5. 이번 파일럿의 한계

- 코더 1명(LLM) — 사람 코더 κ 검증 전. 묶음 5개·기사 18건.
- 기사는 웹 검색으로 모았다(네이버 API 미사용) → 누락 가능. B02(2024년 4월 스웨덴 연구)는 당시 보도를 찾지 못했다.
- 일부 기사에서 리드 추출이 부제·바이라인·사진 설명을 잡았다 → 코더는 실제 첫 두 문장으로 코딩(자동값과 차이 발생).
- 댓글 미수집 → RQ3 는 아직 판단 불가.

## 6. 다음 단계 제안

1. 네이버 API(`search-news`)로 B02 보강, `discover`로 묶음 후보를 넓혀 20개까지.
2. 팀원 2명이 이번 18건 중 6~8건을 블라인드로 코딩 → Claude 코딩과 κ 비교(코드북 수정 여부 판단).
3. '확실성 강화(최종 판명·종결·위험 없다)' 변수 추가 여부 결정.
4. RQ3를 유지할지: 일반지·통신사 기사 위주로 댓글 수집 가능 여부부터 확인.
